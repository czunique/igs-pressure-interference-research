# 本轮质量审查说明

1. 初步覆盖与基线时长检查后，发现部分邻井在起泵前已发生50–60 MPa压力跃升，十分钟中位基线会产生错误归因。因此加入基线平稳性审查，原数据保留。
2. 后续检查发现一条从约63 MPa降至0.72 MPa的曲线。将近零压力复核范围统一设为<1 MPa，且必须同时存在≤5 s采样下>5 MPa跳变。这类记录需要工况证据区分，仅列待复核，不判为无风险。修订前506样本结果保存在质控修订前审计目录；最终样本名单以结论目录为准。
3. DTAIDistance在本环境对部分受限路径使用剪枝时返回无穷距离。已关闭剪枝，使用完整动态规划并核查距离有限、对称及零对角。
4. 所有现有数据用于首轮探索，没有封存外部测试平台。后续训练及外测不得把本轮全部数据建立的标签字典当作从未接触测试平台。
