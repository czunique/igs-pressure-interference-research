## 研究结论边界

3180条曲线中采用参考形态约束划分目标五类，并保留额外形态。压力响应强中弱尚不是独立标定的损害风险。跨平台模型使用1016个组合、21个验证组，XGBoost宏平均F1为0.275，快速稳定型召回率为0。SHAP表征模型关联，不能替代因果和微地震验证。天然裂缝定量结果主要覆盖泸201H5。
